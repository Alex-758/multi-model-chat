> 子代理全量通读 main/preload/渲染层全部 innerHTML 赋值点 + `node -e` 实测 + 历史修复复核（211be66 密钥架构、d7c10d3 CSP、9f46c4b、ba84261、1205294 均确认在位且未回归）。

## 发现与处置

### A1 · 导入数据的数值字段直接拼进 innerHTML（持久化 HTML 注入）— P1 已证实 ✅已修复
- 位置：`src/renderer/js/ui-chat.js` statusHtml()/usageBadge()/roundUsage()
- 证据：`if (res.ms) h += '<span class="badge">' + res.chars + ' 字</span>'` —— ms/chars/usage.input|output 来自磁盘/导入数据，可为任意字符串。node 实测 `{ms:'<img src=x onerror=…>'}` 注入成功。
- 影响：CSP（script 无 unsafe-inline）拦住脚本执行，但可注入可见标签+行内样式做钓鱼覆盖层、注入外链；随 store.json 持久化。
- 修复：新增 `num()` 强制 `Number()`+`Number.isFinite` 归一，非数字按 0 丢弃；usageBadge 的 tip 同步改为纯数字拼接（不再需要 esc）。回归：e2e-sessions 注入用例见 07 号报告（A1 部分由 smoke-roundops/e2e 覆盖）。

### A2 · 渲染层传入的 baseUrl 可收到真实密钥（密钥隔离边界残余缺口）— P2 潜在 ✅已修复
- 位置：`src/main/main.js` resolveModel()
- 证据：`Object.assign({}, m, { apiKey })` —— 渲染层可传 `baseUrl:'https://evil.com'`，主进程把真 key 以 Authorization 头发过去。
- 修复：连接参数（baseUrl/apiFormat/fullUrl/provider）一律以主进程存量 db 为准，渲染层传值仅对已存在的服务商生效。回归：e2e-app「伪造 baseUrl 不能引流密钥」（断言 /evil 路径 0 命中、真实端点收到 Bearer k1）。

### A3 · markdown.js 代码块占位符未校验索引 → 会话渲染持续崩溃 — P3 已证实 ✅已修复
- 位置：`src/renderer/js/markdown.js`
- 实测：`md('hello\n\u0000B5\u0000\nworld')` 抛 TypeError，该会话每次重绘都崩。
- 修复：越界占位符按普通文本输出；行内 `\u0001C` 占位符同款防御（越界输出原文而非 undefined）。回归：e2e-app 新用例。

### A4 · markitdown 回落通道 shell:true + 手工引号 — P3 潜在 ⏸未修复（进路线图）

### A5 · 导出文件名未处理 Windows 保留设备名/结尾点 — P3 ⏸→✅已修复

## 已验证无问题（覆盖面清单）
- **webPreferences**：contextIsolation+sandbox 双开、无 nodeIntegration、webSecurity 未关；preload 白名单方法面（e2e-app 断言 API 枚举），无任意 channel invoke；事件回调只透传数据不透传 ipc 事件对象。
- **导航与弹窗**：setWindowOpenHandler 一律 deny、http(s) → shell.openExternal；will-navigate 仅放行同页刷新；渲染链接 target=_blank rel=noopener。
- **markdown XSS**：抽代码块 → 全文 esc → 行内正则 → 占位符还原顺序正确；12 组实测（javascript:/data:/大写协议/事件属性/单引号 URL/属性转义）全部安全；merge.js 纯文本；byRound 属性比对防选择器注入（ba84261 在位）。
- **密钥**：safeStorage/DPAPI 加密落盘；渲染层永远只有 hasKey；错误提示 slice(160) 不回显密钥；providers/search 无 headers/body 日志。
- **CSP**：default-src 'self'、connect-src 'self'、object-src 'none'、base-uri 'none'；style-src unsafe-inline 为行内样式所需。
- **附件**：mmimg host 白名单正则+二次校验防穿越；临时文档 finally 清理；OCR 走 base64 -EncodedCommand；25MB×6 上限。
- **导入**：JSON.parse own `__proto__` 经 roundtrip 不触达 Object.prototype（node 实证）；主进程过滤+渲染层 normalize 双层；e2e 有原型污染回归。
