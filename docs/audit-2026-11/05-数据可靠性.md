# 05 · 数据可靠性审计报告

> 范围：store.js 原子写/加密/损坏保护、保存时机、退出路径、迁移链幂等、导入导出闭环、多实例、附件生命周期。历史修复（c25583c 会话丢失 7 项、211be66、9f46c4b）复核在位。

## 发现与处置

### D1/D3/B4 · 中间态固化磁盘 + 加载链无终态归位 → 重启后永久"生成中" — P1 已证实 ✅已修复
- 三条固化路径：① retryOne 先 `status='streaming'` 落盘再发请求（ui-chat.js:1703-1705）；② 后台轮流式中用户改会话名/置顶/输入提示词触发整份保存；③ 交叉审查/综合占位落盘。重启后 migrateSessions 只做 merge 折叠/roundId/版本种子，无任何终态修复 → 卡片死锁在 spinner，无重试入口（重试按钮只给 error/stopped）。
- 修复（一处覆盖三条路径）：migrateSessions 内归位——results 的 streaming/searching/pending → 有内容 'stopped'（保留半成品 + 重试按钮）、无内容 'error'（附「上次退出时中断，请重试」）；review items pending/streaming → 'stopped'；空 verdict 标 stopped；空 merge 占位删除。幂等（归位后二次运行 no-op）。
- 回归：e2e-sessions「崩溃残留：streaming/pending 状态加载时归位」（含部分内容/空内容/审查条目/空 verdict/空 merge 五种形态断言）。

### D2 · 退出路径零 flush：关闭窗口丢在途整轮 — P1 已证实 ✅已修复
- window-all-closed 直接 quit，无 before-quit/will-quit 保存；渲染层无 beforeunload；流式一轮几十秒，期间关闭 = 用户消息已落盘、回答整轮丢失需重发重付费。
- 修复：main 拦截 close（一次性）→ preventDefault + 发 `app:flush` → 渲染层 MM.save 完成后 window.close() 放行；渲染层已死时 2.5s 超时 win.destroy() 兜底。preload 暴露 onFlush（白名单断言同步更新）。
- 回归：e2e-window「关闭前自动落盘」——改标题不保存 → 关窗 → 从磁盘读回断言。

### D4 · store.json 损坏时空库启动连带清空全部图片附件 — P2 已证实 ✅已修复
- corrupt → db.sessions=[] → `images.gc([])` 把可由 .corrupt 备份恢复的图片引用全部变成孤儿删除。与损坏保护机制自相矛盾。
- 修复：`if (!bad) images.gc(db.sessions)`。回归：新增 smoke-corrupt 套件（损坏文件 + 白名单命名图片 → 启动后文件仍在、备份已生成），已注册进 test.js。

### D5 · 导入覆盖旧库前无备份无确认 — P2 已证实 ✅已修复
- 修复：① store.snapshot('pre-import') 在覆盖前 copyFileSync 带 时间戳 副本（与多实例 .bak 固定名分离）；② 导入按钮前置 U.confirm 危险确认（文案含备份文件名说明）；③ 成功 toast 显示备份文件名。
- 回归：e2e-deep/e2e-app/e2e-sessions 全部导入用例补确认框处理后通过（新确认框为既有用例的兼容性验证）。

### D6 · 导出备份不含图片附件本体 — P2 已证实 ✅已修复（第二轮：完整方案）
- 导出经 images.exportAttach 把消息引用的图片以 dataB64 内联进备份（同图去重）；导入经 importAttach 物化回 images/、引用改写新 id、dataB64 剥离（物化失败保留原引用走既有文字降级，不阻断）。
- 回归：e2e-app「导出+图片内联+回灌物化」全链路用例（删除本体 → 导入 → 新文件存在 + 引用已换 + dataB64 已剥）。

### D7 · 数据规模无界 + 每次保存全量序列化整库 — P2 潜在 ✅部分修复（第二轮合帧），深层存储进路线图
- 第二轮：MM.save 150ms 尾合帧——一轮对话的 3~8 次全量保存合并为 1~2 次（await 语义不变、configOnly 并存取最大、immediate 直通供关窗 flush）。库体积上限（分文件/SQLite）仍需数据结构决策，保留在路线图。

### D8 · 多实例冲突备份名固定 .bak，乒乓写入覆盖前一份 — P3 潜在 ✅已修复（第二轮）
- .bak-<时间戳> 命名，保留最近 5 份（pruneBaks）。回归：smoke-real「冲突备份带时间戳 + 只保留 5 份」。

### D9 · 写盘失败仅 toast 节流，无退路保障 — P2 潜在 ✅已修复（第二轮）
- MM._dirty 全局脏标记 + 指数退避重试（3s→6s→12s→24s→30s）；关窗 flush 失败弹强提示横门（重试保存/放弃更改并关闭），绝不静默丢数据。回归：新增 smoke-savefail 套件（目录形 store.json 强制写盘失败 → 脏标记/提示/横门/放弃关闭 4 项）。

### D10 · 第二实例静默退出 — P3 ✅已修复（第二轮）

### D11 · 导入会话 id 无去重 / roundId 跨会话撞车 — P3 潜在 ✅已修复（第二轮补齐 roundId）
- normalizeSessions 会话 id 去重（第一轮）+ roundId 跨会话去重（第二轮：重复的换新 uid）。回归：e2e-sessions 去重用例（含 roundId 断言）。
