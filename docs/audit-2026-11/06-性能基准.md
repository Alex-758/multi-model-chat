# 06 · 性能基准报告

## 本次修复中的性能相关项

- **E8 · roundDomLru 重复 unshift 不去重** ✅已修复：同会话连续两次 renderAll 会把「第二新」会话的渲染池误逐出（LRU 判活窗口被同一 id 占满），下次切入冷重建 ~300ms。修复：unshift 前先去重。属命中率修复，无可感知基线差。
- 其余 9 项性能发现（E1-E7/E9/E10）均为「已证实量级」或「潜在风险」，无用户日常可感的 P1，全部进路线图按「增量保存 → 冷开装饰 idle 化 → finalize 两阶段 → 输入阈值」顺序处理。

## 修复后验证

- `npm run test:full` 全绿（126.8s），其中 perf-render（大会话渲染）、perf-stream（流式时延）两套件作为性能回归门通过 → 本次 29 处修复未引入性能回归。
- 内存：无泄漏路径（pending Map 配对删除、mdCache/srcCache WeakMap、roundDom 池 LRU 上界、paintQueue 每帧清空、confirm 监听器用毕即移除——审计逐项确认）。
